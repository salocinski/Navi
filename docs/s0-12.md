# S0-12 — Capture presse-papiers Windows (carte TW-12)

Date : 2026-11-17. Statut : **critère atteint** — prototype fonctionnel.

## Objectif

Capturer le texte sélectionné par l'utilisateur via `Ctrl+C` (presse-papiers Windows),
gérer les formats multiples (Unicode, ANSI, HTML, RTF), restaurer le presse-papiers.

## Prototype

- `scratch/clip_012/` — crate Rust autonome
- API Win32 via crate `windows` 0.58
- Formats supportés : `CF_UNICODETEXT` (prioritaire), `CF_HTML`, `CF_RTF`, `CF_TEXT` (fallback)

## Démonstration

```
=== S0-12 Capture presse-papiers ===

1. Envoi Ctrl+C à la fenêtre active...
   WM_COPY envoyé

2. Ouverture presse-papiers...
   Presse-papiers ouvert

3. Formats disponibles:
   0xC139 : HTML Format
   0x000D : CF_UNICODETEXT
   0xC236 : Chromium internal source RFH token
   0xC1A3 : Chromium internal source URL
   0x0010 : Format_0x0010
   0x0001 : CF_TEXT
   0x0007 : Format_0x0007

4. Lecture contenus:
   Format 0x000D : 176 caractères
   Format 0x0001 : 176 caractères

=== Résultat ===
Texte (176 chars): e33ab-1e3962899c-c7c1078a24-4212474588-d35dddef1a-1a43c8268a-e4ea7f954f-ddca543863-72f3be9e8c-186c0243ce-7dde48a246-bb30c97c74-679842e0ff-22ddc29046-6bd2b9cf71-96bcd36bbf-dbf5c
```

## Points techniques validés

1. **Envoi `WM_COPY`** (`0x0301`) à la fenêtre au premier plan (`GetForegroundWindow`)
2. **Ouverture presse-papiers** `OpenClipboard(None)` — `None` = pas de fenêtre propriétaire
3. **Énumération formats** via `EnumClipboardFormats` + `GetClipboardFormatNameW`
3. **Lecture priorisée** : Unicode (13) → HTML (0xC00E) → RTF (0xC00F) → ANSI (1)
4. **Lecture mémoire globale** : `GetClipboardData` → `GlobalLock`/`GlobalSize`/`GlobalUnlock`
5. **Fermeture propre** `CloseClipboard`

## Formats détectés en test réel

| Code | Nom | Disponible |
|---|---|---|
| 13 (0x000D) | CF_UNICODETEXT | ✅ |

| 0xC236, 0xC1A3, 0x0010, 0x0007 | Formats internes Chromium | ✅ |
