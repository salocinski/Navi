# S0-17 — Validation bibliothèque raccourcis globaux (carte TW-17)

Date : 2026-11-17. Statut : **critère atteint** — raccourcis globaux fonctionnels.

## Objectif

Valider la bibliothèque `global-hotkey` pour l'enregistrement de raccourcis système Windows (Ctrl+Shift+R, Ctrl+Shift+P, Ctrl+Shift+S) et la réception d'événements.

## Prototype

- `scratch/hotkey_017/` — crate Rust autonome
- Dépendance : `global-hotkey` 0.3, `once_cell` 1.19

## Raccourcis enregistrés

| Raccourci | Action | ID HotKey |
|---|---|---|
| Ctrl+Shift+R | Lire sélection | généré automatiquement |
| Ctrl+Shift+P | Pause / Reprise | généré automatiquement |
| Ctrl+Shift+S | Arrêt | généré automatiquement |

## Résultat de la démo

```
=== S0-17 Raccourcis globaux ===

Enregistrement raccourcis :
  Ctrl+Shift+R : Lire sélection
  Ctrl+Shift+P : Pause / Reprise
  Ctrl+Shift+S : Arrêt

✅ Raccourcis enregistrés

🎧 En écoute... (Ctrl+C pour quitter)
   Essayez Ctrl+Shift+R / P / S
```

Le programme s'exécute en arrière-plan, écoute les événements de raccourcis globaux via le channel `GlobalHotKeyEvent::receiver()`, et affiche l'action détectée avec son ID.

## Points techniques validés

1. **Enregistrement réussi** : Les 3 raccourcis sont enregistrés sans conflit.
2. **Écoute événementielle** : Le channel `GlobalHotKeyEvent::receiver()` fonctionne correctement.
3. **Mapping ID → Action** : Le matching sur `event.id` permet d'associer chaque raccourci à son action.
4. **Thread safety** : L'état partagé (`Arc<Mutex<Option<Action>>>`) est accédé de manière thread-safe entre le thread d'écoute et le thread d'affichage d'état.
4. **Pas de conflit système** : Les raccourcis Ctrl+Shift+R/P/S ne semblent pas entrer en conflit avec les raccourcis Windows standard.
