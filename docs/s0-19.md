## Points techniques validés

1. **`OutputStream` + `Sink`** : Architecture rodio standard, thread-safe
2. **`Sink::append()`** : Gestion file FIFO native, lecture séquentielle transparente
3. **`Sink::pause()` / `play()` / `stop()`** : Contrôles de base fonctionnels
4. **`Sink::set_volume(f32)`** : Contrôle volume linéaire 0.0-1.0
5. **`Decoder::new(Cursor<Vec<u8>>)`** : Lecture depuis mémoire sans fichier temporaire
5. **`sleep_until_end()`** : Blocage jusqu'à fin de lecture (utile pour démo synchrone)
